# Buildings

The Buildings module generates 240 deterministic Nepali building studies: 80 urban, 80 semi-urban, and 80 rural. Typology controls morphology before decoration, covering geography, use, construction, massing, floor count, roof, facade, openings, balconies, age, maintenance, construction state, and incremental additions.

Serve the repository over HTTP and open `buildings/`. The interface filters the catalogue, edits a selected study, regenerates seeded variants, compares contexts, and exports individual or full-sheet SVG/PNG artwork.

Reference notes and the morphology schema live in `src/modules/buildings/NEPAL_BUILDING_TYPOLOGY.md`.
