# Scenes

Open `scenes/` through the project web server. The adaptive composer supports 12 recipes, natural-language keyword parsing, guided controls, continuous adaptation sliders, multiple aspect ratios, named layer visibility and locking, selective regeneration, undo/redo history, saved editable scenes, research emphasis modes, and SVG/PNG export.

The primary canvas is not an asset sheet. Buildings, trees, people, roads, and mobility come from their existing generators through adapters and are positioned according to scene context, depth, frontage, road, and infrastructure rules.
